존재하지 않는 역 - 공식 홈페이지

실행 방법
1. 압축을 풉니다.
2. index.html을 더블클릭합니다.
   또는 VS Code에서 index.html을 열고 브라우저로 실행합니다.
3. 별도 Python/Node/npm 설치는 필요하지 않습니다.

구성
- 세계관 설명
- 캐릭터: 기관사 / 안내자 / 소년 / 괴이를 부르는 자 / 부기관사
  캐릭터 선택 시 프로필과 설정표가 함께 변경됩니다.
- 스토리 미리보기
- 컷씬 미리보기
- 공지사항
- 문의

주요 파일
- index.html
- style.css
- script.js
- assets/ 이미지 폴더
